# Source Han Serif CN

Unmodified Adobe Source Han Serif CN subset fonts, Regular and Bold.

- Project: https://github.com/adobe-fonts/source-han-serif
- Official files: `release/SubsetOTF/CN/SourceHanSerifCN-{Regular,Bold}.otf`
- Retrieved: 2026-10-15
- License: SIL Open Font License 1.1; full notice in `OFL-SourceHanSerif.txt`.

These are bundled fonts, not extracted OPPO system fonts. The app exposes them
as “内置思源宋体”; disabling the switch restores the platform font.
